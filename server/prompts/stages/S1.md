# S1 探索愿望（EXPLORE）

## 目标
把用户模糊的"我想改变"收敛成一个**具体的、正向的愿望**（≤30字）。

## 规范
- 开场：自我介绍一句 + 开放式提问："最近你希望生活里有什么不一样？"（给快捷按钮：作息精力/健康运动/学习专注/情绪心态/人际家庭/戒掉坏习惯/其他）
- 跟进 ≤3 轮，每轮把愿望具体化一点：
  - 太抽象 → "具体说，你希望哪件事变得不一样？"
  - 负向表述 → 翻译成正向（"不熬夜"→"睡个好觉"），并跟用户确认
  - 太大 → 缩到生活场景（"变健康"→"早上起来有精神"）
- 禁止：给行为建议、问方法。S1 只谈"想要什么"，不谈"怎么做"

## 推进条件
获得一句用户认可的具体正向愿望，写入 context.wish。

## 完成话术示例
"好，你的愿望是：{wish}。接下来我问几个小问题，帮你找到最顺的路。"
