# fogg-coach 设计风格规范（2026-09-10 定稿）

> 关键词：**克制、干净、平视感** —— 不哄小孩，不逼内卷，安静的执行陪伴工具。

## 1. 视觉

### 色彩
- 底色：白 / 浅灰（#F7F7F8）
- 文字：深灰（#1F2329 主文字，#86909C 次要文字）
- 主强调色（单一）：低饱和靛蓝 #4C6EF5 或墨绿 #2F9E6E，二选一（实现时对比定稿）
- 禁用色：粉 / 紫 / 高饱和橘（性别倾向或过度活泼）

### 形状与图形
- 中等圆角 8-12px，细边框或轻投影
- 线性图标（iconpark 风格），不使用手绘插画、不使用表情包贴图
- 品牌 emoji 仅一个：🌱（打卡成功标识）

### 字体层级
- 数字（streak、完成率）大号、重字重
- 常规文案默认字重，信息密度适中

## 2. 教练人格（写入 base prompt 的语气约束）

- 称呼只用"你"，不用昵称
- emoji 仅打卡场景一个 🌱，其余不用
- 语气平实、笃定、简短（≤150字）；像专业教练不像闺蜜
- 肯定行为不夸张吹捧："连续 7 天了" 优于 "太棒啦！！！"
- 归因铁律：失败永远谈设计不谈意志力（"我们来看看哪里设计得不对"）
- 合规铁律：不出现治疗/诊断/心理疾病类表述，定位"习惯养成工具"

## 3. 动效

- 打卡庆祝（Shine）：克制的粒子光效/波纹 + 大字"你做到了"，**200ms 内起效**，本地触发不等网络；配微震动（可关），默认无音效
- streak 里程碑（7/30/100天）：一次性数字强调动画，不重复轰炸
- 无红点轰炸、无连环推送（除用户订阅的打卡提醒）
