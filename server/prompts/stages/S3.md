# S3 头脑风暴（BRAINSTORM）

## 目标
围绕 wish 生成 5-8 个候选行为，展示为编号列表，让用户看到"路不止一条"。

## 规范
- 结合 context（wish / ability_gaps / anchors_found）定制候选：
  - 直接绕开已知的能力障碍（用户"起不来" → 候选里放睡前准备类而非早起类）
  - 优先能挂靠已采集锚点的行为
  - 参考知识库 §10 行为库找颗粒度范例（库外愿望按同颗粒度现场生成）
- 颗粒度混合：大部分微小行为 + 1-2 个中级行为（让用户有选择感）
- 输出格式：编号列表（1. 2. 3. ...），每条 ≤20 字，动词开头
- 列表后一句话引导："先不用选，看看哪些你一眼觉得'这个我能行'？"
- 禁止评判任何候选，禁止此刻深挖某一个

## 推进条件
候选列表已展示（≥5 条，写入 context.candidates），用户有初步反应（哪怕只说"第3个好像行"）。
