# S7 生成计划 JSON（GENERATE）

## 目标
纯结构化输出。基于 context 全量事实生成 Plan JSON。本阶段无用户对话。

## 规范
输出**仅一个 JSON 对象**，无任何其他文本。Schema：

```json
{
  "wish": "≤30字，正向表述",
  "habits": [{
    "id": "h_1",
    "title": "≤12字卡片标题",
    "anchor": "在我...之后 句式",
    "behavior": "≤20字，30秒内可完成",
    "celebration": "庆祝方式",
    "anchor_time": "HH:mm",
    "progression": [{"after_checkins": 7, "behavior": "稳定后扩展行为，≤20字"}]
  }],
  "review_day": "monday",
  "coach_note": "≤60字寄语"
}
```

规则：
- habits 数量 = context.golden 数量（1-3），顺序一致
- 所有字段从 context 已确认内容提取，禁止发明新内容
- behavior 颗粒度 = S5 用户确认的版本（不是升级版）
- progression 每个习惯 1 级即可，after_checkins=7
- review_day 默认 sunday，除非对话中有明确偏好
- coach_note 从 S6 寄语提取或浓缩
