# 社区动态规划（2026-09-10 定稿）

> **北极星**：让用户看到优秀的人，感受到优秀的氛围。
> 社区是打卡的放大器，不是独立产品；做"榜样感"，不做"热闹感"。

## 一、现有功能（M3 随上线）

- 内容源：打卡记录分享（默认不分享，主动开启；streak 有亮点时出现成就感文案引导）
- 内容形态：习惯标签 + 文字 + 图片（语音不做）
- 全量机审：msgSecCheck / imgSecCheck
- 交互：仅"加油"点赞；无评论
- 流：时间倒序；删自己内容；举报入口

## 二、三档演进

### 档1 MVP（M3）
保持薄社区，目标只有一个：分享动作顺滑。
- streak 亮点时的引导文案（"连续5天了，分享给大家看看？"）

### 档2 活跃期（上线 1-2 个月后，看数据）
1. **今日话题**：官方每日/每周轻话题（后端配置，可 LLM 生成+人工过），解决冷启动
2. **加油通知闭环**：收到"加油"轻通知（订阅消息额度内，可关）
3. **教练精选（榜样位）**：每周 LLM 初选+规则过滤挑 5 条"坚持故事"置顶——**这是北极星的核心承载**：让坚持者被看见，让围观者被感染。精选维度：streak 里程碑、真实有细节的记录、中性真实（不选鸡汤味浓的）

### 档3 生态期（与 v2 团队打卡联动）
1. 好友动态流（圈子动态独立 tab）
2. 战报广场：圈子战报分享（天然传播属性）
3. 里程碑勋章分享卡：7/30/100 天 streak 预渲染分享图（带小程序码，拉新入口）

## 三、明确不做

| 不做 | 理由 |
|------|------|
| 评论/弹幕 | 实时 UGC 运营+审核成本翻倍，破坏克制氛围 |
| 关注/粉丝 | 做了关注就是社交产品，个人主体过不了审 |
| 算法推荐 | 时间流够用；榜样靠精选不靠算法 |
| 匿名发帖 | 违规溯源需要 |

## 四、氛围护栏（写进运营与产品原则）

- 优秀 = 坚持、真实、具体；不 = 鸡汤、炫耀、完美主义
- 精选与话题文案遵守中性风格（design-style.md）
- 若未来出现攀比倾向（数据信号：删记录率上升），优先调文案而非加功能
