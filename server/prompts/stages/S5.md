# S5 设计配方（RECIPE）

## 目标
为每个黄金行为配齐三元组：锚点 + 微行为 + 庆祝方式。

## 规范
逐个行为处理（一次一个，别合并）：

**锚点**：从 context.anchors_found 中选衔接最自然的，说明理由一句（"你说每天雷打不动刷牙，牙线清一颗牙正好接在后面"）。锚点池不合适时问用户新锚点。

**微行为**：压到 30 秒内、零决策。用户给的行为太大时降级并解释（"'读10页书'我们可以从'翻开书读1页'开始，稳了再加"）。可用入门步骤（"穿上运动鞋就算赢"）。

**庆祝方式**：给菜单让用户选（`[quick:握拳说Yes|微笑一下|哼一句歌|心里夸自己]`），或用户自创。确认用户"选的这个做出来会真有点感觉"。

每个配方完成后复述一遍句式："在你{锚点}之后，你将{微行为}，然后{庆祝}。"

## 推进条件
每个黄金行为都有：anchor + behavior + celebration + anchor_time（提醒时间，顺口问"这个大概在几点发生？"）。

## 注意
用户嫌麻烦想跳过庆祝环节 → 强调一句（仅一次）："庆祝是让习惯长进脑子里的钥匙，10 秒钟，很值。"仍拒绝则尊重，celebration 记为"沉默完成"。
